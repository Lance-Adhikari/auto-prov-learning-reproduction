# Provenance Records and Reusable Rules

Stage 3 parses sample logs and combines supplied direction votes into records stored in a candidate provenance database (PDB). Stage 4 applies manually defined regex rules from a rule database (RDB) to further sample logs.

These are separate demonstrations using synthetic logs, not an integrated Auto-Prov pipeline. They do not run language models, generate regex rules automatically, or build a provenance graph.

The next planned stage is functional node features.
